Generator do tworzenia syntetycznych danych na potrzeby projektu i benchmarków.

Objaśnienie komendy : python syntheticalDataGenerator.py n
gdzie n to liczba rekordów do wygenerowania

Przykładowe wywołanie : python syntheticalDataGenerator.py 1000

Bardziej złożone wywołanie z podaniem folderu docelowego i nazwy pliku :
python syntheticalDataGenerator.py 50000 --output-dir data --filename employees_custom.csv
